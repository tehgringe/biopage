# Inner Aphelion / Bio Page

A high-impact, futuristic 3D landing page for a Cybersecurity Professional. Built with Next.js, React Three Fiber, and Tailwind CSS.

## Features

-   **Atmospheric 3D Scene**: Particle fields, interactive digital globe, and volumetric fog.
-   **Holographic HUD**: Floating UI with "glitch" typography and neon aesthetics.
-   **Responsive Design**: Optimized for all devices.

## Tech Stack

-   Next.js 15
-   React Three Fiber
-   Tailwind CSS
-   Framer Motion

## Getting Started

```bash
npm run dev
# or
yarn dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
